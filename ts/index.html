Live API (Go server)

Calls the Go SDK's HTTP surface (GET /v1/avatars/{seed}.json) through the Vite dev proxy and renders the returned descriptor with the TS renderer above. Start either Go binary in ../go/cmd/ first (default :8080; override with KOLAVATAR_API_URL).

Advanced overrides

These knobs opt out of the v1.3 p-knob path (which always uses edge-first sampling): setting coverage or strand_length routes generation through the composer instead so motif-based output honours the override. salt isolates the seed namespace (same seed + different salt → different design). min_score clamps the effective score up. score_bands tunes how many discrete bands the score is bucketed into for the composer's PRNG seeding.

Gallery (100 designs)

A pre-generated catalogue showing the generator's range across the four most ornate symmetry groups (4mm_d, 4, 2mm, 2m_dm_d) on a 13×13 grid. Each row is one (symmetry, seed) pair; the five columns walk score 0.20 → 0.95 so progression reads left-to-right. Click any tile to load that descriptor into the main canvas above.
